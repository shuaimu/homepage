# Source figure

`fast21-utilization.png` is the unmodified 852 × 842 chart image embedded on
page 13 of Siying Dong's FAST 2021 presentation. It was extracted directly with
Poppler `pdfimages`, not redrawn or digitized. It presents the same four-metric
survey as Figure 3 of the paper.

- [USENIX presentation page](https://www.usenix.org/conference/fast21/presentation/dong)
- [Original slide PDF](https://www.usenix.org/sites/default/files/conference/protected-files/fast21_slides_dong.pdf)
- Authors: Siying Dong, Andrew Kryczka, Yanqin Jin, Michael Stumm.
- Original PDF: 48 pages; downloaded September 20, 2026.
- Original PDF SHA-256: `d0ece2700caf400efe08ea82ba60a9f7c6e34dbbe239dc6daac97b794994c2ba`.

The lecture cites both the talk page and the paper's Figure 3. The chart remains
an attributed source figure rather than an editable reconstruction of values
that the source does not tabulate.
